# Decision rule

The one-cell OpenVoice V2 CPU smoke is a strict kill-or-expand experiment.

- scientific PASS at all four machine gates -> authorize only the exact four-cell matrix with unchanged code/model/source/reference policy/tau/seed;
- any scientific FAIL -> retire direct OpenVoice V2 tone-color conversion without tuning;
- infrastructure-only failure -> repair harness only, with no scientific parameter or input change;
- human listening remains unauthorized at one-cell stage.

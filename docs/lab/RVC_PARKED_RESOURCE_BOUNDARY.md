# RVC learned-character track — parked at resource boundary

RVC remains scientifically live but is not the active experiment.

Accepted evidence remains immutable:

- CPU feasibility rejected only on bounded execution cost, not speaker science;
- Lucie neutral corpus: `dataset-pass`, 64 accepted clips, 352.16 s, aggregate WER 0.0270855905, expansion acceptance 54/60 = 0.90, zero retries/substitutions;
- frozen RVC v2/32k package: fixed seed 1234, batch 4, 200 epochs, F0=1, RMVPE CUDA, HuBERT v2, no tuning/fallback;
- unresolved boundary: training package requires exactly one CUDA GPU with >=10 GiB VRAM, and user-provided/self-hosted CUDA is unavailable.

This is a PARK, not a scientific rejection. It may be resumed only if a zero-cost end-to-end GPU execution/evidence path is proven without weakening the frozen package, or if an already-available project resource satisfies the frozen hardware contract.
